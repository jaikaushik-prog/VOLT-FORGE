# 20-minute user trial

The slide has no real user evidence yet. Five people trying the app gives Desirability something true to point at. Report only what happens.

## Who

Three engineering students and two working engineers, if you can get them. Anyone who hasn't seen the app. Write down how many you actually got.

## Setup

Run the app on your laptop and start a new project. Say this and nothing more:

> We want to see if this tool makes sense without help. Think out loud. If you get stuck, that's our fault, not yours.

Don't explain anything or point at the screen. If someone is stuck for 2 minutes, give one hint and write it down.

## Tasks

1. **Build it.** "Set up a four-cell backup for a Raspberry Pi 5 and test it."
2. **Read it.** "Which cell works hardest? How do you know?"
3. **Improve it.** "How few cells could do this job? Find out."

## After

Ask these, in this order, and write down their words:

1. Which task was hardest, and why?
2. How would you have answered this question without this tool?
3. Rate 1 to 5: "I'd use this for a real battery project."
4. What would stop you using it?

## Fill in

Use `results_template.csv`, one row per person. Time each task with a phone.

## What can go on the slide

Plain counts only, for example "4 of 5 people found the smallest design without help". If it goes badly, say that too, and fix what broke. Never round up, never add a person who didn't take part, and never quote someone without asking them.
