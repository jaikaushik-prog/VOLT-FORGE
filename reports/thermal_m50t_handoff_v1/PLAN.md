agent. The electrothermal_engineer agent owns new test-103 importer, test and
report files. Root coordinates review, current-status documentation and GitHub.

The engineering scope is the already designated development family. The agent
must preserve all other thermal experiments, frozen electrical models and all
earlier receipts. Its prospective procedure and source seal precede full-record
analysis. There is no parameter fit, thermal UI, module coupling or optimizer
in this handoff.

Root will review the source, diagnostic outputs and limitations, run appropriate
integration checks, and check the preserved history by recorded hashes. The two
living status files are archived byte-for-byte before edits in preservation_map.
Earlier receipts must continue to identify their historical versions; no old
receipt or numerical source is rewritten to make a new check pass.

Keep raw/extracted numerical arrays local. Push verified code, compact diagnostics
and evidence metadata to the existing authorized repository.
