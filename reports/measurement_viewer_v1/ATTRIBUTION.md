# Public dataset attribution and derived material

The ID01 measurements used in this viewer were already publicly released by:

**Milan Plzák, Šimon Berta, Andrej Ürge and Martin Baťa (2026). P45B 1s4p Battery
Module Measurement, version v1. FreeTwinEV / Slovak University of Technology in
Bratislava. [Zenodo, DOI 10.5281/zenodo.18405243](https://zenodo.org/records/18405243).**

The public Zenodo record and the archive's `LICENSE.txt` explicitly identify
the [Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/),
which permits redistribution and adaptation with attribution. The public ZIP's
MD5 is `dea7c0e8c7146f517d71979ac546249d`. The previous intake receipt verifies
that the local original ZIP has this checksum and that all 32 extracted files
match it byte-for-byte. These are public battery sensor measurements, not private
user/laboratory records. No new private experimental data were supplied.

VOLT-FORGE's changes are derived presentation and diagnostics: elapsed time,
sample counts, channel ranges, missing/gap counts, chart point selection, source
row excerpts and plot screenshots. The original CSV is unmodified. Source current
signs and units are retained. The screenshots, ID01 summary JSON, one exact-source
row JSON and descriptive report in this directory derive exclusively from that
public ID01 record. No other record's measurement outcomes were opened.

The full original dataset is excluded from this Git repository. Access restrictions
within the viewer protect future assessment allocation; they do not restrict the
dataset's licence or the user's ability to obtain the public original. No author
endorsement of VOLT-FORGE is implied. Module validation remains pending.
